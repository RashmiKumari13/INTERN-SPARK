# FocusList

FocusList is a mini interactive to-do list app built with plain HTML, CSS, and JavaScript DOM manipulation.

## Features

- Add tasks with priority and optional due date.
- Mark tasks complete or active.
- Edit and delete existing tasks.
- Filter by all, active, or done.
- Search tasks and sort by newest, priority, or due date.
- Live progress stats and due-soon counts.
- Light/dark theme toggle.
- localStorage persistence.

## Source Code

- `index.html` - app structure and controls.
- `styles.css` - responsive layout and visual design.
- `script.js` - DOM state, events, rendering, filters, and localStorage.

## Run Locally

Open `index.html` in a browser. No build step is required.
