# Premium Mobile-Friendly Personal Portfolio

Welcome to the source space of a stunning, state-of-the-art, fully responsive personal portfolio website customized for developer **Rashmi Kumari**. This showcase features premium dark aesthetics, glassmorphic panel layers, dynamic neon gradient glow accents, fluid typing transitions, scroll-activated indicators, active-offset navbar scrollspy, and mobile-friendly hamburger integrations.

---

## 🚀 Key Features

*   🌌 **Deep Space default Dark Mode**: Modern dark-theme visual style featuring curated neon teal-cyan and violet gradient typography and borders.
*   🔮 **Glassmorphism Design System**: Sleek cards utilizing high-quality backdrop-blur filters (`backdrop-filter: blur(16px)`) and glowing interactive hover states.
*   ⌨️ **Handcrafted Pure JS Typewriter Loop**: Dynamic hero subtitle typing simulation displaying rotating professional developer roles without heavy external library footprints.
*   ⚡ **Scrollspy & Sticky Top Navigation**: Smooth scrolling sticky header featuring background density adjustments on scroll and automated active section detection.
*   📶 **On-Scroll Skills Progress Animator**: Smooth IntersectionObserver animation that fills technological progress meters when the Skills section enters the user's screen.
*   🎯 **Dynamic Project Category Filters**: Custom responsive card grids that filter items inline (All, Frontend, Full Stack, UI/UX) with micro-scale animations.
*   📬 **Validated Floating Label Contact Form**: Interactive input elements with focus glow styles and animated success alert toast confirmations upon transmission.
*   📱 **Responsive-First Architecture**: Hand-tested fluid grids looking razor-sharp on extra-small mobile devices, tablets, laptops, and ultra-wide desktops.

## 🛠️ Technological Stacks & Assets

1.  **Semantic Structure**: [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML) markup, including semantic block dividers (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
2.  **Custom Styling Engine**: [Vanilla CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS) containing root variables, custom scrollbars, float keyframes, and custom webkit layout overlays.
3.  **Responsive Layout System**: [Bootstrap v5.3.2](https://getbootstrap.com) (via fast CDN delivery) for bulletproof responsive grid containers, column spacing, and mobile toggle collapse behaviors.
4.  **Icons & Typography**:
    *   Fonts: **Inter** & **Space Grotesk** from [Google Fonts](https://fonts.google.com).
    *   Icons: [Bootstrap Icons](https://icons.getbootstrap.com) and [FontAwesome v6](https://fontawesome.com) CDNs.

## 🌐 Deploying to GitHub Pages (Live Hosted Version)

Hosting this portfolio for free on the web using **GitHub Pages** takes less than 2 minutes. Follow this step-by-step guide:

### Step 1: Create a GitHub Repository
1.  Log in to your [GitHub Account](https://github.com).
2.  In the upper-right corner, click the **+** dropdown and choose **New repository**.
3.  Set the Repository Name (e.g., `rashmi-portfolio`).
4.  Set visibility to **Public** (required for free GitHub Pages hosting).
5.  Leave "Initialize repository with a README" unchecked, then click **Create repository**.

### Step 2: Push Your Source Code
Open your terminal (PowerShell, Command Prompt, or Git Bash) inside this project directory (`f:\WEB DEVLOPMENT\INTERNSPARK\task 1`) and execute these commands:

```bash
# Initialize local git environment
git init

# Add all portfolio files (index.html, style.css, script.js, README.md)
git add .

# Create initial commit
git commit -m "feat: initial commit of premium responsive portfolio website"

# Rename default branch to main
git branch -M main

# Link to your newly created GitHub repository
# (Replace USERNAME and REPO-NAME with your details)
git remote add origin https://github.com/USERNAME/REPO-NAME.git

# Push code to GitHub
git push -u origin main
```

### Step 3: Activate GitHub Pages
1.  Navigate to your repository page on [GitHub](https://github.com).
2.  Click on the ⚙️ **Settings** tab located below the repository title.
3.  In the left sidebar menu, click on the **Pages** menu under the "Code and automation" heading.
4.  Under the **Build and deployment** settings:
    *   **Source**: Select *Deploy from a branch*.
    *   **Branch**: Click the dropdown, choose **main**, and keep the directory set to `/ (root)`.
5.  Click the 💾 **Save** button.

### Step 4: Access Your Live Portfolio
*   GitHub will compile the page. Within 1 to 2 minutes, refresh the Page settings tab.
*   A green box will appear at the top displaying your live URL:
    👉 `https://USERNAME.github.io/REPO-NAME/`
